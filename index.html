Ocean-block-bot

Ocean-block-bot is a small personal assistant that runs a private Telegram chat for a single person, its developer. It helps plan the day in 5-minute blocks, sends reminders, saves notes, and can add events to, and read events from, the developer's own Google Calendar.

What it does with Google Calendar

  • Creates calendar events when the developer asks for them in the private chat.
  • Shows the developer's upcoming events in the same private chat.
  • It does not edit or delete events, and it does not access any other Google data.

This app is not offered to the public and has one user.
