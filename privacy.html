Privacy policy

Last updated: October 8, 2026

Ocean-block-bot is a personal tool with a single user, its developer. It is not offered to the public.

What data the app accesses

With the developer's permission, the app uses the Google Calendar scope that allows viewing and creating calendar events on the developer's own calendar. It uses this only to add events the developer asks for and to show the developer their upcoming events.

How the data is used and stored

  • Calendar information is shown only to the developer, in a private Telegram chat.
  • The Google login token is stored in a private file on the developer's own computer or server.
  • Messages the developer types to the bot are sent to an AI service (Anthropic's Claude API) so the bot can understand the request.

Sharing

The app does not sell Google user data, does not use it for advertising, and does not share it with anyone else. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting access

The developer can remove the app's access at any time in their Google Account security settings, and can delete the saved login file.
